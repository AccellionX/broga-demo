# Bro-ga · sales demo

Front-end concept demo for a custom Bro-ga platform (replacing Wix + Zapier + MailerLite + Gymcatch).

**Stack:** Next.js 14 · TypeScript · Tailwind · shadcn-style UI · Recharts · react-leaflet  
**Data:** Seeded mock data in `src/lib/mock-data.ts`. No backend, no real payments.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Roles

Use the floating pill (bottom-right) to switch:

- **Customer**: home, venue finder, booking
- **Teacher**: mobile register (Phase 2)
- **Owner**: admin dashboard (Phase 3)

## Deploy

Push to GitHub and import on Vercel. Zero config.
